# 音频

这些声音是本项目里用 WebAudio 现写的旋律和噪音，不是买来的配乐，也没有人声配音。

| 状态 | 实现 | 说明 |
|---|---|---|
| 整理 | 8 个音循环，收在同一组主音 | 准备、领奖后 |
| 战斗 A / B | 两句不同的低音循环 | 普通关轮换 |
| 精英 / 首领 / 最终首领 / 剧情 | 各自一句 | 同一状态不会再开一份 |
| 胜利 / 战败 | 四个短音，不循环 | 播完回到整理或停在最终首领 |
| 短喊、怪物、操作 | `src/ui/audio.ts` 里的合成音 | 短喊约 20%，同角色 2.5 秒一次，不用战斗随机流 |

交叉淡化大约 1.1 秒。对白时把音乐压低。第一次点击才创建 AudioContext。切到后台会暂停。2 倍速只加快战斗步进，不改音乐的 playbackRate。

没有录制的角色配音。字幕就是对白。
