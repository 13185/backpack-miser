# 音频

这些声音是本项目里用 WebAudio 现写的旋律和噪音，不是买来的配乐，也没有人声配音。实现在 `src/ui/bgm.ts` 和 `src/ui/audio.ts`。两处共用同一个 `AudioContext`，第一次指针点击之后才创建。

| 状态 | 实现 | 说明 |
|---|---|---|
| 整理 | 8 个音，每音 1 秒，一句 8 秒，收在主音 | 准备、领奖后。不是 60–180 秒的乐曲 |
| 战斗 A / B | 两句不同的低音，同样 8 秒循环 | 普通关轮换 |
| 精英 / 首领 / 最终首领 / 剧情 | 各自 8 秒一句 | `setBgm` 遇到同一个循环 id 不会再开一份 |
| 胜利 / 战败 | 四个短音，间隔 420 毫秒，不循环 | 播完回到整理，或停在最终首领 |
| 短喊、怪物、操作 | `src/ui/audio.ts` 里的合成音 | 短喊约 20%（`Math.random`，不用战斗随机流）。喊出来之后，同角色 2.5 秒内不再喊 |

交叉淡入大约 1.1 秒，淡出大约 1.0 秒。主音量增益 0.18。对白时 `duckBgm` 把主音量收到 0.05，对白结束回到 0.18。设置里的音效开关同时关掉音效和音乐。切到后台时 `visibilitychange` 会 `suspend` 这个 `AudioContext`，回到前台再 `resume`。战斗场景同一事件里把 `paused` 设为真，逻辑时间停住。2 倍速只加大 `stepCombat` 的步长和 Phaser 的 `timeScale`，不改音乐的 `playbackRate`。

没有录制的角色配音。字幕就是对白。开场和首领落败用 `public/art/cinema` 的画，图画加载失败时才退回色块。
