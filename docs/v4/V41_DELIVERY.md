# 3.8.0 交付（V4.1）

3.9.0 的样板图、注册表和仍缺的姿态见 `docs/v4/ART_STATUS.md`。下面是 3.8.0 当时的记录。

平衡标记 `3.8.0-wear-ref`。相对 3.7.1，这一版改的是穿戴规则和界面，不改生命、攻击、售价、掉率和锻造概率。背包硬顶仍是 6×6。扩容仍是 28 金、42 金，然后献祭到 6×6。

## 规则

- 主手和护甲只存 `mainHandId` / `armorId`。物品留在原格，邻接照旧。主手标记不再多打一次。
- 备用箱 2 件，只收武器和衬甲。旧档超过 2 件的进 `legacy`，只能取出或出售，不删除、不进战斗。
- 读档时，旧的 `bin=hand/armor` 会尝试放回格子并记下引用；放不下就进待整理，不白给效果。
- 从待整理或备用拖进槽时，先找一个真实空位。没有空位就拒绝。

## 界面

一级入口是背包、寻装、市集。方案和战报是次级。待整理贴在背包下面。主手槽和护甲槽可以拖入、拖出。按钮仍调用同一套命令。

玩家界面不再直接显示 wood、metal、guard、counter、special。扩容按钮写当前尺寸到目标尺寸，例如 5列×4行 → 5列×5行，新增 5 格，28 金。

## 已验证

- `npx vitest run`：19 个文件，172 项通过。其中包括原格主手、邻接伤害、单演员、护甲占格、备用箱 2 件、旧档迁移、熔炉水破、1 倍和 2 倍步长。
- 浏览器拖放（Chromium，本地 dev）：匕首拖进主手后背包仍占格；从主手槽拖回原格后标记消失；旅行衬甲拖进护甲槽后出现「甲」并留下占位。录像 `wear-drag.webm`，截图 `desktop-worn.png`、`desktop-armor.png`、`phone-360.png`、`phone-390.png`、`phone-430.png`。手机槽实测 56×56。
- 第 12 关页面正文没有 wood/metal/guard/counter/special。产卵说明只留一行。

## 未验证

- 没有手打熔炉、没有在浏览器里点完第 50 关三种结局。
- 没有 100 个种子的通关率。这里不补一个数字。
- 正式绘稿、首领多姿态和元素图集没有做，见 `ART_STATUS.md`。
