# 穿戴与元素（3.7.0）

同一件装备的 `bin` 决定位置：`hand`、`armor`、`reserve`，或没有 bin 时用坐标表示背包，坐标也没有就是临时区。

主手攻击使用武器自己的间隔和基础伤害，不调用邻接宝石。备用箱里的实例不会进入 `createCombat` 的演员列表。

护甲未穿时只是 2×2 物品。穿上后提供抗性，不提供护盾，因此不触发吉利达幸运符。

直接伤害：先按旧规则扣一次护甲得到 P。无元素则伤害就是 P。有元素则 `0.4P + 0.6P × (1 - 抗性/100)`，最后取整，非零至少 1。战术防御再对这次直接伤害向下取整乘 0.6。毒伤不走这套拆分。

抗性表在 `ELEMENT_MATRIX`。木受火击是 -10。玩家抗性来自穿上的那一件甲，范围夹在 -20 到 60。
