# 测试报告（3.7.1）

命令：`npm test`。发布前再跑 `npm run build`。浏览器只做了启动冒烟：新游戏能打开，设置显示 3.7.1。

环境：Vitest 4.1.12。没有跑 100 种子到达率。

已验证：

- 元素公式例子。
- 主手、备用箱、护甲抗性。
- 两套方案只存引用；卖掉后提示失效，物品数量不增加。
- 不同元素合成默认留下主装备；赌输时主装备等级和元素不变。
- 第 20 关商店刷新后有一件 1–3 级衬甲。
- 寻装不改主线生命、金币、关卡。
- 熔炉：水伤在预警内凑够 4% 就取消重击，且这次没有 `heavyStrike`；火伤不计入。1 倍步长和 2 倍步长的胜负、时间、血量、破势次数一致。
- 手动战术防御把 10 点攻击打成 6 点，冷却中第二次无效。自动模式在重击剩余不到 1 秒时会开一次。
- 原有战役节点测试仍通过。

未验证：

- 手机上拖动合成时的元素选择面板。
- 浏览器里手点熔炉破势和战术按钮的完整一场。
- 旧档打开、章节回档、50 关三结局。
- 五种策略的大规模模拟。没有到达率数字。
