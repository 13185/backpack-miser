# 测试报告（3.7.0）

命令：`npm test`，然后 `npm run build`。

环境：仓库里的 Vitest 4.1.12。浏览器长流程（360/390/桌面、第 11 关教学、两套方案、50 关三结局）这次没有逐项点完。

结果：`npm test` 通过，163 项。构建在类型错误修好之后才能作为发布步骤；以提交时的 `npm run build` 为准。

已验证：

- 元素公式的 6 个例子。
- 主手、备用箱、护甲抗性开关。
- 寻装不改主线 HP、金币、关卡。
- 第 35 关不再带旧 overheat，预警后护甲归零。
- 原有战役节点测试，包括第 20 关转折和第 30 关第二铭刻。

未验证：

- 手机宽度上的拖动和战术按钮。
- 手动防御、破势成功取消重击的完整对局。
- 旧档在浏览器里打开后的迁移。
- 寻装重复练习、章节回档是否带回奖励。

已知问题：

- 没有两套命名整备方案。
- 不同元素合成没有单独的选择面板，默认留下目标那一件的元素。
- 商店和战利品不直接刷衬甲。
- 自动防御和熔炉破势没有做 2 倍速对照记录。
- 没有五种策略的大规模模拟，报告里不写到达率。
