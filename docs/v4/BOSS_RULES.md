# Boss 规则（3.7.0）

抗性来自 `bossElements`。5、10 关没有元素。15 关起普攻按 60% 无属性 / 40% 主元素，重击按 20% / 80%。玩家抗性为 0 时合计仍等于原来的伤害。

| 关 | 主元素 | 抗性 |
|---|---|---|
| 15 | 木 | 木 40，金 -15，火 -10 |
| 20 | 金 | 金 40，火 -15 |
| 25 | 水 | 水 50，土 -15 |
| 30 | 土 | 土 50，木 -15 |
| 35 | 火 | 火 60，水 -20。只走熔炉循环 |
| 40 | 金 | 金 50，火 -15 |
| 45 | 木 | 木 50，金 -15，火 -10 |
| 50 | 阶段金 / 水 / 火 | 同属性 50，对应弱点 -15 |

第 35 关：三次普攻后进入 3 秒预警，下一击是 1.8 倍（生命低于 40% 时 2 倍）火重击，然后护甲归零 3 秒。预警期间对本体造成的水伤达到最大生命 4% 时取消这一击，直接进入散热。旧的 overheat、重击和半血盾不再挂在这一关。

第 20 关仍然只有 70%/35% 盾和每 4 击 1.5 倍重击。数值见 `PHASE_A.md`。
