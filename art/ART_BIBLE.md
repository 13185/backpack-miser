# 《背包守财奴》美术规范 ART_BIBLE

版本：art-v1 · 与 V2 玩法规格同步 · 参考锁定：商旅 / 守卫 / 游侠 九宫格原图

## 1. 统一方向

原创 **2D 手绘暗黑童话**：漫画表现 + 适度夸张的冒险角色。神秘、有幽默感，有厚实的装备与财富质感。

人物、敌人、装备、背景、界面、特效必须属于**同一个视觉世界**。

### 禁止混入
- 写实摄影
- 3D 塑料质感
- 像素风
- 现代扁平图标
- 明显不一致的二次元/动漫素材
- 大头萌系或写实人体比例（以参考图比例为准）

## 3. 线条 · 块面 · 材质 · 光照

1. **描边**：深色，轻微粗细变化，形体清楚。
2. **明暗**：明确块面 + 适量手绘纹理（布料褶皱、皮革磨损、金属刮痕）。
3. **材质可辨**：布料 / 皮革 / 金属 / 药水玻璃 / 宝石切面。
4. **光照**：偏右上主光，角色有清楚受光面与背光面；背景光更弱。
5. **阴影**：角色落地阴影与刀光/火花/粒子**尽量单独图层**，不烘焙进每一帧身体。

## 4. 角色身份锁定（不可换脸/换装/换惯用手）

### 商旅 Merchant（默认主角）
- 矮壮体型；大鼻子、黑色乱发与短胡须。
- 土黄色披风；鼓胀巨大木架背包、毯卷、挂壶、钱袋。
- 常抱溢出金币的陶罐；性格机灵贪财，遇险优先护财。
- **防御（必须用最新修改版）**：低重心弓步撑地；侧身用巨大背包挡击；一臂护头，另一臂紧抱钱袋；咬牙用力，有抵抗冲击的力量感。
- 参考九宫格中的防御格若与上述不符：运行时仍可用该格作占位，但 **须标记待重生**（见 ASSET_MANIFEST `merchant_defend`）。

### 守卫 Guard
- 宽肩厚重；黑发短胡须；小头盔。
- 旧钢甲、米白罩衣（胸前十字）、蓝披风；宽剑 + 长方形厚盾。
- 可靠认真，带一点笨拙幽默感。

### 游侠 Ranger
- 敏捷修长；棕色长辫；绿尖兜帽与金色纹样；暗红围巾；皮甲；双弯刃。
- 自信、狡黠、反应敏捷。

锁定内容：脸型、发型、服装结构、配色、身材比例、武器形制、关键饰品。不同动作不得换脸、换衣服、换左右手或凭空增加装备。

说明：九宫格是姿势参考，**不是**可串播的连续动画。连续帧需后续按本圣经 + 参考图批量重生；在那之前运行时 **hold 关键帧**，并可用轻微呼吸缩放辅助，但不可拉伸整张立绘冒充走路/挥刀。

动作质量要求（重生时）：预备→发力→收招；格挡架势→承击→恢复；受伤反馈清楚；移动有步态；喝药正确收纳武器；胜利/战败体现职业性格；同动作各帧武器长度与脸型一致。

## 7. 装备 · 遗物 · 敌人

- **装备**（V2 共 12 种 × 3 级）：家族轮廓一致；等级用角标/边框/少量强化装饰区分；背包格子尺寸下仍可识别。
- **遗物**（24）：统一独立框架；清楚轮廓；禁止 24 个相似光球。
- **敌人**：普通轮廓简单；精英加强识别装饰；Boss 大轮廓 + 阶段变化。蓄力/破绽/护甲/毒/狂暴用一致视觉提示，不能只靠换色。

## 8. 四章背景

1. **贪婪矿洞**：暗蓝岩壁、矿轨、矿灯、少量金矿。
2. **铁锈牢城**：铁门、石墙、铁锈、锁链、冷灰。
3. **幽毒巢穴**：幽绿菌类、蛛网、潮洞；保留角色辨识度。
4. **黄金王库**：暗紫石柱、暖金财富；避免满屏金光。

远/中/近景分层；战斗区留空；不遮挡血条与意图 UI。

## 9. 界面

旧金属、深色皮革、羊皮纸材质。**关键数值由代码渲染文字**，不画死在图里。按钮触控足够大。

## 10. 战斗接入约束

- 动画由游戏状态驱动；伤害由规则系统决定，**不由动画命中次数决定**。
- 刀光多段 ≠ 多次扣血。
- 统一战斗时钟；倍速/暂停/后台一致。
- 调试：Animation Preview 可切换状态、显示脚底线与锚点；正式游戏隐藏。

## 敌人 / NPC / 背景统一标准（2026-10-29 补充）
- **唯一基准**：商旅/守卫/游侠原图。所有新图生成时必须把至少一张职业原图 + 一张已通过的同类新图作为参考图。
- **描边**：深色墨线，外轮廓粗、内部细，略有粗细变化；禁止无描边的厚涂、禁止均匀等宽矢量线。
- **块面**：2–3 级明确的手绘明暗块（cel-like），配少量笔触纹理；禁止电影感柔光、写实皮肤与材质、3D 高光。
- **比例**：人形敌人与主角同为「略夸张的敦实冒险比例」（头身约 1:4–1:5），不是大头萌系；首领在游戏中按主角画布 1.12× 显示。
- **细节密度**：与主角同级——主要道具 1–2 件 + 章节特征 1 个（潮汐藤壶/镜片/炉栅/祝祷光/债契卷轴/金脉）；512px 下轮廓可读。
- **画布**：1024×1024 透明 PNG，水平居中，脚底 y≈928（Phaser origin 0.5, 0.906），另出 512 版；NPC 为半身，底边贴画布底。
- **抠图**：纯 #00FF00 绿幕生成 → `art/tools/key_green.py`（软键+去溢色+1px 收边）。避免角色本身大面积纯绿（如绿皮哥布林会被抠穿）。
- **背景**：与 ch1_mine 同一手绘块面画法，地面占下 1/3 且平坦；整体亮度/对比低于角色（必要时 Brightness≤0.9、Contrast 0.9）。章节配色：港口冷青水汽 / 镜砂灰紫 / 工坊焦黑暗红 / 圣堂灰白旧金 / 王庭深紫旧金 / 核心黑金脉动。
- **NPC 区分**：四人发型、头饰、主色、道具互不相同（露米铜红短发护目镜灯；老铆光头灰须焊镜护臂；乌先生鸦喙面具黑燕尾账本；伊芙深棕侧辫无帽绿白医师服背药箱）。
- **装备图标**：128px 透明 PNG，同一张 3×3 绿幕表一次生成以保证同风格，物件居中占 ~88%。
